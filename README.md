## Development and Characterisation of Alginate-Based Scaffolds: Foundational Study Toward Bioprinting Cardiac Ablation Phantoms

### 📋 Project Overview
Cardiac ablation is a minimally invasive procedure for treating arrhythmias, with growing global demand. Current research relies on animal models (costly, ethically contentious) or synthetic phantoms that lack cellular responses, neither is ideal.
This project develops alginate-based scaffolds with cardiac-equivalent mechanical and electrical properties that support cellular integration, establishing foundational knowledge for future 3D bioprinting cardiac ablation phantom
